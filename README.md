# PYATIGORSK HUB

Сайт студии: https://spedyterr-rgb.github.io/pyatigorsk-hub/

- `main` и `gh-pages` — сам сайт (одинаковые).
- `game-files` — файлы игр; при отправке в эту ветку они сами выкладываются в Releases.
- `data/games.json` — список игр и файлов, `data/history.json` — ежедневные замеры скачиваний.
