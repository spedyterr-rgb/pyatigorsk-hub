Если не запускается

Windows пишет «Система Windows защитила ваш компьютер»
  1. Так Windows встречает любые программы без платной подписи издателя.
  2. Нажми «Подробнее», затем «Выполнить в любом случае».
Как поставить APK на телефон
  1. Скачай файл и открой его из загрузок.
  2. Телефон спросит разрешение на установку из этого источника — разреши.
  3. Нажми «Установить».
